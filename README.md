# 📊 Pricing Portal

A zero-cost, cloud-based supplier pricing management system built for Plumbing World .

**No hosting fees. No coding required to set up. Automated reminders for non-standard cycles.**

---

## What This Does

Instead of managing pricing submissions via email chaos, the Pricing Portal:

✅ Centralizes all supplier submissions in one place  
✅ Validates Excel files in real-time (catches errors before you review)  
✅ Stores contracts per supplier with version history  
✅ Automatically reminds suppliers of deadlines  
✅ Alerts you to mid-year cycle suppliers and 6-month pricing windows  
✅ Exports validated files ready for your macros  
✅ Tracks everything with audit logs
